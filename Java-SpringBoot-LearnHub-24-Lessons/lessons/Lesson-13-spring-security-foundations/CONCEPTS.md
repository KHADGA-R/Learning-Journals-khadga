# Lesson 13 — Spring Security

## Deep dive

Study `SecurityFilterChain; BCrypt; DatabaseUserDetailsService` and how they enforce **default deny and least privilege**. Differentiate authentication, authorization, transport contracts, and application-service policy. Model direct HTTP attackers rather than trusting Angular route guards.

## Failure scenarios

Consider anonymous requests, CSRF omissions, cross-user IDs, stale sessions, and data leaks. Document expected status codes and persistence behavior.
