## Study method

Read each lesson's README and CONCEPTS, copy and adapt the code in CODE-EXAMPLES, run the verification commands, complete the exercises and quiz, and mark the checklist. Lessons are incremental: **do not copy an earlier controller or DTO over a newer implementation**. Maintain separate commits in your actual source repositories.

## Security and accuracy

Never commit .env, passwords, webhook secrets, real payment data, database dumps, or private user records. Earlier instructional material has known API drift (POST/PATCH publishing, CourseRepository delete signatures, DTO fields, enrollment/refund provenance). See [integration caveats](./INTEGRATION-NOTES.md).
