# Course Roadmap

**Foundation:** Lessons 1–4 — Java 21, records, OOP, collections and errors.

**Backend:** Lessons 5–12 — Spring Boot, REST, validation, PostgreSQL, Flyway, JPA, CRUD and search.

**Security and frontend:** Lessons 13–16 — Spring Security, sessions, roles, ownership and Angular integration.

**Marketplace:** Lessons 17–20 — wishlist, enrollment, curriculum, publishing and payments.

**Production engineering:** Lessons 21–24 — testing, OpenAPI/observability, Docker/CI/CD and capstone.

Use the [lesson index](./README.md) for links and [integration notes](./INTEGRATION-NOTES.md) for compatibility issues.
